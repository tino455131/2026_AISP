Discord 團隊協作助手：系統流程圖

合併版由 team_bot/start.mjs 啟動兩個程序，對 Discord 使用同一個 Bot 帳號。Node.js 處理指令、語音和 AI 互動，Python 記錄文字訊息。

合併版的程序與資料流

從根目錄執行 node team_bot/start.mjs。兩個程序使用根目錄 .env 的 VOICE_BOT_TOKEN、DISCORD_GUILD_ID 與 BOT_DB。

也可以分開啟動兩個 Bot。單獨的文字 Bot 使用 TEXT_BOT_TOKEN，提供文字記錄與 /ping。單獨啟動 Node.js 仍可使用 /meeting，會議發言由 Discord 即時讀取。Bot 操作與已知限制

SQL｜共用資料庫

根目錄的 sqlite_api.py 提供共用的 SQLiteStore，集中處理所有元件的 SQLite 連線、建表和讀寫，包含 AI demo 的會議查詢與進度追蹤。預設資料庫是 data/messages.sqlite3，可用 BOT_DB 指向其他位置。

聊天
messages、backfill_state、deleted_messages 記錄文字和匯入進度。
語音會議
voice_sessions、voice_lines、voice_session_summaries 保存錄音資訊、逐字稿與摘要。
文字會議
text_meetings 保存起訖訊息 ID、摘要和引用。獨立的文字記錄程序會將一般聊天寫入 messages。
測試追蹤
demo_tasks、demo_inquiries、demo_progress_updates 保存確認、送達與進度狀態。ai_demo 透過 SQLiteStore 新增任務、記錄詢問與回報進度。

面向使用者的查詢應在應用層確認來源與受眾權限。底層 SQLite 讀取不具備 Discord 授權功能。合併版的文字記錄目前會保存一般聊天，spec.md 所述的保存限制仍待落實。

文字 Bot｜即時記錄與文字會議

Python 文字記錄

  1. Discord 訊息事件合併版的文字記錄程序接收指定伺服器的訊息事件。text_logger.py
  2. 匯入與即時同步Python 啟動時匯入歷史。收到新訊息時寫入 SQLite 並印到 Terminal，也會同步編輯和刪除。bot.py
  3. SQLite 聊天紀錄依伺服器、頻道與訊息 ID 保存。授權 reader 會先核對使用者的 Discord 權限再讀取。channel_access.py

Node.js 的 /meeting 指令

  1. 組長開始會議記錄開始訊息，將進行中的會議保存到錄音資料夾內的 JSON。meetings.js
  2. 組長結束會議向 Discord 讀取起訖訊息之間的成員發言。
  3. 摘要與原頻道紀錄產生摘要、決定與候選待辦，保存至 text_meetings 並將紀錄貼回來源頻道。summarize_text_meeting.py

語音 Bot｜錄音、轉寫與查看

  1. 開始錄音組長可下 /record start。自動錄音預設開啟，未限制頻道時會掃描可用的語音頻道。commands.js config.js
  2. 錄音設定direct 預設直接納入，可按「不要錄我」；ask 需先按同意。錄音時保存 WAV 和 manifest。consent.js
  3. 停止後轉寫轉寫程式把逐字稿寫入 SQLite。預設使用本機 Breeze，可換 OpenAI API 或自訂轉寫器。ingest_recording.py
  4. 產生摘要與查看按鈕有逐字稿時產生摘要。點按查看時，show_session.py 透過 transcript_reader.py 驗證來源頻道權限，回覆只給點按者。summarize_session.py show_session.py transcript_reader.py

測試時可用 node team_bot/start.mjs --consent ask --auto-record off，由組長開始並等成員同意。 錄音的已知限制

AI｜摘要、問答與測試追蹤

meeting_ai 處理兩種會議的摘要。預設 simple，可切換 OpenAI、Claude Code 或自訂實作。摘要器設定

  1. 選擇一場會議/ai tasks 或 /ai ask 會先檢查來源頻道的存取權。文字會議向 Discord 讀原文，語音會議讀逐字稿。ai.js
  2. 私下回覆ask.py 產生回答，tasks.py 產生任務候選。送出前再檢查存取權限。Discord 回傳空原文時，使用已保存的會議摘要。ask.py tasks.py local_data.py
  3. 測試版進度追蹤組長確認後，符合來源權限的負責人收到一輪私訊。按鈕回報會保存狀態，再私訊有來源權限的組長。sqlite_api.py

/ask 一般問題直接交由 OpenAI 回答。需要目前頻道歷史時，get_current_channel_history 透過授權 reader 呼叫 SQLiteStore，回覆只給提問者。 AI 工具開發教學

測試追蹤只發一次詢問。回報的資料可見範圍見 Team Bot 已知限制。
