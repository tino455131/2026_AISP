# AI Usage Guidelines

We updated these rules after the Week 12 cross-team review.

## Database checks

For AI-assisted changes that read or write task data, list the checks you ran with a test database in the PR. Mark any checks you could not run and explain why.

## AI disclosure

Every PR describes what AI produced and links to the [prompt log](../PROMPT_LOG.md) when AI was used. If the author worked without AI, write “AI assistance: none.”

## Teammate review

Keep at least one teammate review, or two if [`DECISIONS.md`](../DECISIONS.md) changes. For AI changes that affect permissions or scope, a reviewer records that disallowed requests were declined and that private records stayed hidden.
